Executive summary

Metabase Starter (Cloud) costs ~Rp 659M/year (forecasted) while running the exact same basic security tier as the Free version, locking out our internal security audit logs (query_execution), locking AI agents out of the internal metadata database, and routing Gemini Enterprise (ge-mcp) traffic outside our Google Cloud network. If the goal is maximum security, full AI/MCP capability, and full auditability, our two practical choices are Option 1: Hardened Self-Hosted on GCP with Cloud Armor WAF (~Rp 13M/year) or Option 3: Metabase Pro Cloud (~Rp 1.39B/year).

3. Key decision takeaways

Plain-language summary of the trade-offs across each path.

Why Metabase Starter (~Rp 659M/yr) is a bad trade-off

  • Same security features as Free: Starter does not add Row-Level Security, column permissions, or corporate SAML SSO.
  • Removes our security audit logs: Starter hides the internal Postgres database (database_id = 4) and does not include Pro's Audit Log UI. We lose the ability to track who ran what query or exported data (which was essential for our August Komdigi report).
  • Weakens AI & Gemini Enterprise: Locks AI agents out of the internal database for cross-dashboard impact checks and routes ge-mcp traffic outside our GCP network.

When to pick Metabase Pro Cloud (~Rp 1.39B/yr)

  • Zero capability loss for Antigravity & AI: Creating and updating dashboards directly from Antigravity works 100% identically via the REST API, and Pro includes built-in Usage Analytics + Audit Logs to replace raw database_id = 4 queries.
  • Adds true enterprise security: Unlocks Row-Level Security (data sandboxing), SAML SSO, and MCP tool permission controls, while Metabase handles all server patching automatically.
  • 1-day migration: Can be migrated in ~1 day using Metabase's built-in cloud snapshot tool. The only downside is the cost (~Rp 97.6M/mo today, growing to ~Rp 133.5M/mo).

Why Tableau (~Rp 1.69B/yr) disrupts AI & operations

  • Annual upfront payment required: Unlike Metabase, Tableau requires a 1-year upfront contract (~Rp 1.42B to Rp 1.69B paid upfront) with no monthly pay-as-you-go option.
  • Loses SQL-native AI dashboard building: In Metabase, every chart is a SQL query that AI can create or edit surgically via API. In Tableau, dashboards are 10,000+ line desktop .twb XML files; tableau-mcp cannot read chart SQL or surgically edit a single chart on a dashboard.
  • 3 to 6 months of rebuilding: Requires our 6 analysts to manually rebuild 100+ dashboards and 1,000+ cards from scratch, while breaking ge-mcp and Modibot.
